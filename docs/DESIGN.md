# Một Ngày Đi Chùa — visual language

An immersive game, with a quiet invitation rather than a marketing page. The 3D map is the main visual on the entry screen and becomes the playable world without replacing the backdrop.

- Background: warm ivory `#f7f5ec`; text: pine `#354438`; primary: moss `#465e43`; secondary: muted sage `#68705f`; terracotta roofs; grey-blue clothing.
- Headings: Lora, regular, generous line height. UI: Be Vietnam Pro, readable and restrained. System fonts remain available offline.
- Thin borders, small rounded corners, translucent parchment HUD; no neon, reward widgets, levels or inventory.
- Landing composition: left-aligned invitation, right-hand temple view, small bottom activity descriptions. Game: room count above, chat below left, gestures below right.
- Visible labels and focus outlines, focus-contained dialogs, meaningful loading/error/empty states, non-color status text. Core play targets desktop; smaller screens show a device note.
- UI transitions respect reduced-motion. Scene animation is deliberately limited, DPR capped at 1.5 and shadow maps at 1024.

The UI/UX skill search returned a general minimalism pattern rather than a game-specific layout. Only its applicable accessibility, focus and spacing guidance was used; the visual direction follows spec v1.2.
